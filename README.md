A dependency-free Node 22 interpreter for the official tiny stack ISA. It preserves 32-bit arithmetic, trap precedence, and output written before a trap.

```sh
MAKEFUN_INPUT_DIR=/path/to/practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
